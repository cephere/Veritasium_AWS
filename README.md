<h1>VERITASIUM: A BENCHMARKING SYSTEM FOR FAKE NEWS DETECTION</h1>

<div>
  <h3>Overview</h3>

  <p align="justify">
    This is a thesis the utilizes the capabilities of Amazon Web Services(AWS), Github and Python. The models are stored within the AWS
    and the backend process is also handled by AWS. Furthermore, the frontend is code in React.js is stored in Github and hosted by AWS Amplify, 
    the backend frontend connection done by using API.
    <br><br>
    To know more about the thesis, read the abstract provided below. Note that this branch is only the Matthew's version of the project which is not final,
    and the backend code is not provided only the frontend. The models are also not provided in the repository but is privately stored
    by the researchers.
  </p>
